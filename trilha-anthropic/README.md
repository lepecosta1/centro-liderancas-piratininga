# Trilha Claude Academy — do zero às certificações Anthropic

Roteiro de estudos com **todos os cursos oficiais e gratuitos da Anthropic**, na ordem em que fazem sentido estudar, terminando nas certificações oficiais.

📄 **Página para compartilhar:** [`index.html`](./index.html) — abre no navegador, funciona offline, tem checkboxes que salvam o progresso.

> Catálogo conferido em **21 de agosto de 2026**. A fonte da verdade é sempre o [catálogo oficial](https://anthropic.skilljar.com/).

---

## Antes de tudo — por que os links "não abrem"

Os cursos **não saíram do ar**. A plataforma foi rebatizada para **Claude Academy** e todo curso fica atrás de login: clicar no link direto sem estar logado cai numa tela de cadastro que parece erro.

1. Crie a conta gratuita em <https://anthropic.skilljar.com/> — só pede e-mail.
2. Confirme o e-mail e deixe a aba logada. Daí em diante todos os links abrem direto.
3. Em cada curso, clique em **Enroll**. Sem matrícula não há certificado.
4. Baixe o certificado ao concluir — cada curso emite o seu.

As aulas são em inglês, com legendas automáticas.

### Os quatro exames

Todos pela **Pearson VUE**, 120 min, aprovação em 720/1000, validade 12 meses com renovação gratuita no prazo.

| Código | Exame | Para quem | Preço |
|---|---|---|---|
| CCAO-F | Claude Certified Associate — Foundations | Uso de Claude em funções de negócio | US$ 99 |
| CCDV-F | [Claude Certified Developer — Foundations](https://anthropic-partners.skilljar.com/claude-certified-developer-foundations-certification) | Aplicações na API e no Agent SDK | US$ 125 |
| CCAR-F | [Claude Certified Architect — Foundations](https://anthropic-partners.skilljar.com/claude-certified-architect-foundations-certification) | Sistemas com Claude Code, MCP e agentes | US$ 125 |
| CCAR-P | [Claude Certified Architect — Professional](https://anthropic-partners.skilljar.com/claude-certified-architect-professional-certification) | Entrega ponta a ponta | US$ 175 |

**Rota recomendada:** CCDV-F depois da Fase 04, CCAR-F depois da Fase 05.

## O que mudou em relação à trilha antiga

- **Nomes/URLs**: `claude-with-google-vertex` agora se chama *Claude on Google Cloud*; `introduction-to-agent-skills` aparece como *Introduction to agent skills*. Os slugs continuam os mesmos.
- **Cursos novos** que não existiam na lista original: *Claude Platform 101*, *Claude Code 101*, *Introduction to subagents*, *Introduction to Claude Cowork*, *AI Fluency for Builders*, *AI Capabilities and Limitations*, *Driving enterprise adoption of Claude*.
- **Reordenação**: *Claude Code 101* passa a vir antes de *Claude Code in Action*; *Claude Platform 101* antes de *Building with the Claude API*; subagents e skills sobem para antes do MCP, porque é lá que multi-agente começa de verdade.
- **Certificações**: adicionadas — não existiam na lista original e ficam numa plataforma separada.

Durações são estimativas de estudo, não números oficiais. Preços em dólar, referência de julho de 2026.
