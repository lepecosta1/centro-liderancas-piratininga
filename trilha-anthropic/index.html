Antes de tudo — por que os links "não abrem"

Os cursos não saíram do ar. A plataforma foi rebatizada de Claude Academy e todo curso agora fica atrás de uma tela de login: se você clica direto no link do curso sem estar logado, cai numa página de cadastro que parece erro. Resolva isso uma vez e todos os links passam a funcionar:

  1. Crie a conta gratuita em anthropic.skilljar.com. Só pede e-mail — não precisa de conta Claude, nem cartão.
  2. Confirme o e-mail e deixe a aba logada aberta. Daí em diante, qualquer link desta página abre o curso direto.
  3. Matricule-se em cada curso clicando em Enroll. O curso só aparece no seu painel — e só emite certificado — depois da matrícula.
  4. Baixe o certificado ao concluir e publique no LinkedIn. Cada curso emite o seu, separadamente.
  5. Marque aqui. As caixas desta página ficam salvas no seu navegador — dá pra fechar e voltar depois.

O catálogo em português ainda não existe: as aulas são em inglês, com legendas automáticas. Ative as legendas e a velocidade 1.25× — a maior parte da trilha fica bem confortável assim.

A trilha, fase por fase

Fase 00

Preparação

~30 min

Conta criada, plataforma entendida, primeiro curso matriculado. É o passo que a maioria pula — e é por isso que a maioria não termina.

SETUP·~30 min

Criar conta e explorar o catálogo

Passe os olhos nos 20 cursos antes de começar. Saber o que existe muda a forma como você estuda o primeiro.

Fase 01

Fundamentos de IA

~4 h

Antes de qualquer prompt: o que a IA faz bem, onde ela falha, e o vocabulário que o resto da trilha assume que você já tem.

AIF-101·~2 hBase

AI Fluency: Framework & Foundations

O curso que a Anthropic construiu com pesquisadores acadêmicos. Apresenta o framework 4D — Delegation, Description, Discernment, Diligence — que é a espinha dorsal de tudo que vem depois. Se você só fizer um curso, faça este.

AIF-110·~1 h

AI Capabilities and Limitations

Onde o modelo alucina, onde ele é confiável, e como calibrar sua confiança. É o antídoto contra os dois erros clássicos: confiar demais e desistir cedo demais.

CLD-101·~1 hBase

Claude 101

Claude no trabalho de verdade: Projects, artifacts, upload de arquivos, memória. Curto e direto ao ponto.

Fase 02

Produtividade e primeiros builds

~5 h

Sair do chat e começar a delegar trabalho de verdade — inclusive trabalho que não é código.

AIF-201·~1,5 hNovo

AI Fluency for Builders

A versão do AI Fluency para quem constrói coisas, não só usa. Substitui, na prática, o "for Students" para o seu objetivo.

CWK-101·~1,5 hNovo

Introduction to Claude Cowork

Cowork é o Claude executando tarefas longas de várias etapas sobre os seus arquivos — sem você escrever código. É o caminho mais curto entre "usar IA" e "ter um agente trabalhando pra você".

CC-101·~2 hBase

Claude Code 101

Da instalação ao primeiro projeto. Feito para quem não é engenheiro de software — não pule achando que é básico demais, ele apresenta CLAUDE.md, subagents, skills, MCP e hooks, que são o mapa das fases 3 a 5.

Fase 03

Claude Code a sério

~6 h

Aqui a trilha vira multi-agente pela primeira vez. Subagents e Skills são literalmente o seu objetivo final — só que dentro do Claude Code, que é o ambiente mais fácil pra aprender.

CC-201·~2,5 hBase

Claude Code in Action

Sessões longas sem perder o controle: escrever CLAUDE.md que o Claude realmente obedece, empacotar procedimentos como skills, impor regras com hooks e distribuir tudo em plugins.

CC-210·~1,5 hMulti-agente

Introduction to subagents

Criar sub-agentes com /agents, delegar tarefas para eles e manter a conversa principal limpa. Este é o curso mais próximo do seu objetivo de multi-agentes — e ele vem bem antes do MCP.

CC-220·~2 hMulti-agente

Introduction to Agent Skills

Skills são instruções em markdown que o Claude aplica sozinho na tarefa certa. Aprenda a criar, compartilhar via repositório, distribuir em plugins e conectar cada skill a um subagent especialista.

Fase 04

Plataforma, API e nuvem

~9 h

Sair da linha de comando e colocar Claude dentro dos seus sistemas. Os dois cursos de nuvem são intercambiáveis — faça o da nuvem que você usa.

API-101·~2,5 hNovo

Claude Platform 101

O ponto de entrada atualizado para desenvolvedores: ferramentas nativas (web search, code execution, web fetch), skills, servidores MCP e padrões de gestão de contexto. Comece por aqui, não pelo curso de API.

API-201·~3 hBase

Building with the Claude API

O curso mais denso da trilha: chamadas de API, prompting avançado, tool use, RAG, avaliações (dataset de teste + correção automática) e arquiteturas de agente. As avaliações caem na certificação.

CLOUD-GCP·~2 hEscolha uma

Claude on Google Cloud (Vertex AI)

Rodar Claude dentro da sua conta Google: autenticação, regiões, tool use, RAG e MCP no Vertex. Faça este se sua infra já é Google.

CLOUD-AWS·~2 hEscolha uma

Claude with Amazon Bedrock

O mesmo conteúdo no mundo AWS: conversas multi-turno, ferramentas com JSON Schema, pipelines RAG, extended thinking e prompt caching.

Fase 05

MCP e sistemas multi-agente

~6 h

O objetivo final: agentes que conversam com serviços externos e entre si, em produção.

MCP-101·~3 hMulti-agente

Introduction to Model Context Protocol

Construir servidores e clientes MCP do zero com o SDK Python, dominando as três primitivas — tools, resources e prompts. É o protocolo que conecta qualquer agente a qualquer serviço.

MCP-201·~3 hMulti-agente

Model Context Protocol: Advanced Topics

Sampling, notificações, acesso a sistema de arquivos e transportes. Sampling é a peça que falta: é o que permite um servidor MCP pedir uma inferência de volta ao modelo — a base de arquiteturas multi-agente reais.

Fase 06

Certificação

~4 h + exame

As provas oficiais não estão no catálogo público — ficam na Anthropic Partner Academy, uma plataforma separada. Entrar no Claude Partner Network no nível Registered é gratuito e é o que destrava o registro nos exames.

CPN-PATH·~2 hPré-requisito

Claude Partner Network Learning Path

A porta de entrada da rede de parceiros e o primeiro passo formal rumo à certificação.

CPN-ACAD·~2 hPré-requisito

Anthropic Partner Academy — cursos de preparação

Plataforma separada, com login próprio. É onde ficam os cursos de prep e o registro dos exames — inclusive o prep path do CCDV-F.

Os quatro exames oficiais

Todos aplicados pela Pearson VUE (online ou em centro de testes), 120 minutos de prova, aprovação em 720 de 1000 pontos, validade de 12 meses com renovação gratuita se feita no prazo. Múltipla escolha e múltipla resposta baseada em cenários.

CódigoExamePara quemPreço

CCDV-F Claude Certified Developer — Foundations Quem entrega aplicações na API e no Agent SDK US$ 125
CCAR-F Claude Certified Architect — Foundations Quem desenha sistemas com Claude Code, MCP e agentes US$ 125
CCAR-P Claude Certified Architect — Professional Arquitetos experientes, entrega ponta a ponta US$ 175

Rota recomendada para o seu objetivo: CCDV-F depois da Fase 04, e CCAR-F depois da Fase 05. Dúvidas de logística estão no FAQ oficial de certificações.
